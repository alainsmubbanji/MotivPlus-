✦ Présentation

Lunaris AI est l'assistant intelligent développé dans l'écosystème GO Studio. Il est intégré à MotivPlus afin de proposer une expérience conversationnelle capable d'accompagner l'utilisateur dans ses demandes.

L'objectif de Lunaris

Ne pas être simplement un chatbot, mais un assistant capable de comprendre le contexte d'une conversation et d'utiliser différents outils lorsque cela est nécessaire.

Une expérience pensée pour l'utilisateur

Lunaris privilégie une interaction naturelle : l'utilisateur écrit sa demande et l'assistant analyse le contexte afin de produire une réponse adaptée.

🧩 Mémoire contextuelle

La mémoire utilisée pendant une conversation sert principalement à fournir à l'IA le contexte nécessaire pour produire une réponse cohérente.

Important

La mémoire conversationnelle ne signifie pas que Lunaris se souvient automatiquement de toutes les informations personnelles de l'utilisateur. Le fonctionnement exact peut évoluer selon la version de l'application.

Quand la recherche Web est utile ?

  • Actualités et événements récents.
  • Informations susceptibles d'avoir changé.
  • Documentation et ressources en ligne.
  • Informations nécessitant des références.
Toutes les questions ne nécessitent pas le Web

Pour une question générale, une explication, une reformulation ou une tâche de rédaction, une recherche Web n'est pas forcément nécessaire.

🔎 Sources

Lorsqu'une réponse utilise des informations provenant du Web, les sources permettent à l'utilisateur de vérifier l'origine des informations présentées.

🔗 Pourquoi les sources sont importantes ?

Elles permettent de consulter les pages d'origine et de mieux distinguer une réponse générée d'une information provenant d'une source externe.

Utiliser les sources correctement

  • Ouvrez la source lorsque l'information est importante.
  • Comparez plusieurs sources lorsque cela est nécessaire.
  • Vérifiez la date de publication.
  • Privilégiez les sources officielles pour les informations importantes.
Lunaris ne remplace pas la source

Une référence affichée par Lunaris doit être considérée comme un moyen de vérification. Pour les informations importantes, consultez directement la source.

⚙️ Modèles IA

Lunaris est conçu pour pouvoir fonctionner avec différents modèles ou services d'intelligence artificielle selon la configuration disponible.

Architecture multi-modèle
ÉVOLUTIVE

Les modèles disponibles peuvent évoluer. La documentation ne fixe donc pas une liste permanente de modèles afin de rester compatible avec les futures versions de Lunaris.

Pourquoi plusieurs modèles ?

  • Différentes capacités de raisonnement.
  • Différents niveaux de rapidité.
  • Différents contextes d'utilisation.
  • Disponibilité et limites variables selon les fournisseurs.
Disponibilité

Un modèle peut devenir temporairement indisponible, être remplacé ou ne plus être proposé selon le fournisseur utilisé.

⚠️ Limites de Lunaris

🧠
